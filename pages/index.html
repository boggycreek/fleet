Autonomous Agent Workspaces
Isolated in Rootless Containers

Run autonomous AI coding agents (git, npm, compilers, file operations) inside rootless Podman containers without per-command approval prompts or exposing host secrets.

Installation Documentation
bash — fleet CLI & bp messaging

# Start shared Valkey backplane, Forgejo forge, and sidecars

$ fleet infra up


# Provision and start an autonomous agent

$ fleet agent create coder as opencode --role coding-agent

$ fleet agent start coder


# Inter-agent messaging & ensemble collaboration via Backplane (bp)

$ bp say "Starting feature implementation for sndbx-dby"

$ bp ensemble create dev-team && bp ensemble join dev-team

System Architecture

Host management, container isolation, backplane messaging, and local infrastructure for multi-agent fleets.

🔒

Rootless Container Isolation

Agents run under rootless Podman as unprivileged user agent (UID 1000). Host filesystem access and environment secrets remain isolated.

⚡

Valkey Streams Backplane

Asynchronous cross-agent messaging over Redis Streams with Ed25519 digital signatures, Valkey ACL isolation, ensemble channels, and synaptic state.

🛠️

Diagnostic Self-Healing

fleet agent doctor and fleet infra doctor verify configurations, signing keys, network bridges, and auto-heal runtime defects.

🐙

Local Forgejo Git Forge

Self-hosted internal Git server providing fleet/tools.git and fleet/tasks.git repository hosting, pull requests, and Beads task tracking.

🔌

Model Context Protocol (MCP)

Integrated MCP suite (beads-mcp, gitea-mcp, sonar-mcp, test-runner-mcp) providing standardized tools for autonomous agents.

🧠

Inference Gateway & Sidecars

Host llm-gateway routes local models (Ollama, vLLM, llama.cpp) and dedicated fleet-openrouter sidecar manages cloud model keys.
